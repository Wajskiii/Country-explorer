Istraživač država

Otkrij sve informacije o državama svijeta

Klikni u polje za pretragu ili počni tipkati naziv države

O projektu

Istraživač država je web aplikacija koja prikuplja podatke s REST Countries API (restcountries.com) preko Python backend-a. Prikazuje sve bitne informacije o svakoj državi svijeta.

Podaci ažurirani: 2025.

Kako koristiti

  • Klikni u polje ili počni tipkati naziv države
  • Ako klikneš "Usporedi dvije države" možeš odabrat dvije države
  • Klik na "Otvori mapu" vidi lokaciju države na google mapama

Tehnologije korištene za stranicu

Python Flask REST API HTML5/CSS JavaScript

Podaci povučeni iz: restcountries.com/v3.1
